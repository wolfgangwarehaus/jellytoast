jellytoast

A desktop music player for Jellyfin and Navidrome servers —
bit-perfect playback, casting, mini-player, and offline downloads.

GitHub ↗

Self-hosted music with desktop features

Desktop features

Frosted-glass themes in light and dark modes on Windows and Linux. Floating mini player, visualizer, media keys, and notifications.

Bit-perfect playback

FLAC / ALAC / OPUS / DSD playback via mpv.

Cast anywhere

Send music to Chromecast, AirPlay 2, Sonos, DLNA, or Snapcast. A built-in local relay can forward the stream for trickier setups, like Tailscale connections or fully offline playback.

Offline mode

Cache albums, playlists, or your whole library for offline playback.

Install

Ubuntu / Debian / MintDownload the .deb and install it with sudo apt install ./jellytoast_*_amd64.deb — or pipx install jellytoast.
Windows 10/11Download the installer or the portable zip. It's unsigned, so Windows SmartScreen warns on first launch — just click More info → Run anyway.
