jellytoast

A fast, native desktop music player for Jellyfin, Navidrome & Subsonic servers. Bit-perfect audio via mpv. No Electron. Free & open source.

⊞  Windows installer 🐧  Ubuntu / Debian (.deb) GitHub ↗

All downloads — GitHub Releases

🎧 Bit-perfect playback

FLAC / ALAC / OPUS / DSD untouched via mpv. Gapless, ReplayGain, device picker, ALSA-direct output.

📡 Casts to everything

Chromecast, AirPlay 2, DLNA, Sonos, Snapcast — with a built-in proxy that reaches devices your server can't, even offline.

📥 Real offline mode

Explicit downloads with album / artist / playlist cascade and offline-aware browsing.

✨ Frosted-glass UI

Real compositor blur on KDE and Windows 11, honest fallbacks everywhere else. Dark + light, accent colors, HiDPI-crisp.

Install

Pick your platform — every channel ships the same app.

Arch Linuxyay -S jellytoast
Ubuntu / Debian / MintDownload the .deb, then sudo apt install ./jellytoast_*_amd64.deb
Flathubflatpak install flathub io.github.wolfgangwarehaus.jellytoast (submission in progress)
WindowsInstaller or portable zip · winget install wolfgangwarehaus.jellytoast
Any distropipx install jellytoast (needs system mpv/libmpv + Qt 6)
